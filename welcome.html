Shortcut Hint Overlay

Keyboard shortcuts for the site you're on — without leaving the page.

  1. Hold Ctrl for half a second. An overlay appears with the shortcuts for this site, plus the standard Chrome ones.
  2. Lock it with Ctrl + Space (or just click the overlay). Now you can let go of Ctrl and read the list in peace. Esc closes it.
  3. Search with / while it's locked. Type to filter by keys or by what the shortcut does — e.g. tab finds Ctrl + Tab.
  4. Use the arrow keys to walk through the list. Every row is focusable, and the search box is focused automatically when you lock the overlay.

Tip: click the extension icon in your toolbar to see the current site's shortcuts in a popup. To turn the overlay off for a site, use the toggle in that popup, or manage the list in the extension's Options page.
